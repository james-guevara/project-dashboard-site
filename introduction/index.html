About this dashboard

Introduction

This dashboard is a simple place to keep track of ADSI work happening on several fronts.

ADSI depends on several pipelines, analysis workflows, and cohort datasets moving forward together. This dashboard shows the current work and the next practical steps without trying to replace the scientific documentation or the pipelines themselves.

Raw data processing

Track which pipelines are working, what still needs validation, and what should be built next.

Analysis workflows

Track progress on PGS, gene sets, CNV calling, exposure and phenotype preparation, and downstream analyses.

Cohorts

Track which datasets are available, what has been run, and what each cohort still needs.

Start here, then follow the details

The dashboard intentionally stays at a high level, but information shared with the ADSI team should be findable from the relevant cohort, pipeline stage, or action item. Each entry can point to supporting reports, files, figures, documentation, decisions, and related GitHub issues without making every page complicated.

Sharing updates

How information gets added

You do not need to use GitHub to contribute information.

Send an update, result, report, or data location to James or another dashboard maintainer. The maintainer can place the summary in the right section and link the supporting material so others can find it later. AI can help organize the information and keep the dashboard and its underlying records current.

Add this update to the relevant ADSI dashboard item, summarize the result plainly, and link the supporting material: ...
  1. Share the information.Send the maintainer a result, update, file, report, or useful link with enough context to understand it.
  2. Place it in context.The maintainer connects it to the relevant pipeline stage, cohort, analysis area, or action item.
  3. Keep the summary readable.The dashboard shows the current status and main finding; linked records hold the more extensive detail.
  4. Preserve the history.GitHub issues can record decisions and prior updates behind the scenes without requiring every dashboard reader to use GitHub.
Data policy

This dashboard is public. The linked working repository is private, but privacy controls are not a substitute for careful data handling. Do not put participant-level data, credentials, sensitive storage locations, or other protected information in the dashboard or its GitHub issues.
